# customer-shopping-behavior-analysis
An end-to-end data pipeline processing 3,900 retail transactions via Python data cleaning, SQL business querying, and Power BI visualization to decode customer behavior and drive retail strategy.
## Project Architecture
- **Data Preparation (Python):** Cleaned raw datasets, imputed missing review ratings by category median, and engineered age groups.
- **Database & Querying (SQL):** Managed relational data structures and executed analytical queries evaluating customer segmentation, subscription trends, and revenue drivers.
- **Interactive Dashboard (Power BI):** Developed executive-ready visual canvases highlighting KPIs, category performance, and demographic breakdowns.

## Repository Structure
- `data/` - Raw datasets and cleaned CSV files.
- `scripts/` - Python data cleaning and processing code.
- `sql/` - Core business and custom analytics SQL scripts.
- `dashboard/` - Power BI `.pbix` project file and dashboard screenshots.

## Key Business Insights
- Identified top revenue-generating locations and customer age brackets.
- Analyzed subscription behavior, showing that non-subscribers and active subscribers exhibit distinct purchasing volumes.
- Evaluated discount sensitivity and its direct effect on product review ratings and volume.
